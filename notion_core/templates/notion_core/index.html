Notion Core

Every bit of Notion configuration lives here: one pane per account, each with a friendly name and its own integration token. Setting this up fails in two ways that look identical from the cell editor — a bad token, and a good token on a database nobody shared with the integration — so this page tells them apart, per account.

{% if not panes %}
{{ card_head('Get started', icon_name='plug', level=2) }}

Create an internal integration at notion.so/my-integrations and copy its token (it starts with ntn_ or secret_). Read access is all these widgets use. Then share each database with it: open the database in Notion, then ••• → Connections and add your integration. A database that isn't shared never appears and produces no error — the API simply cannot see it.
